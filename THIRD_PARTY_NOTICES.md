# Third-party resources

This repository contains original skill instructions, documentation, and validation tooling. It links to external design resources but does not bundle their components, media, fonts, logos, or screenshots.

The MIT license in this repository does not relicense external content. Before integrating any external component or asset, check the specific source's license, attribution requirements, and download terms.

Anthropic Skills, Vercel Agent Skills, and the Agent Skills specification informed the repository organization. Their skill bodies and implementations have not been copied into this repository.
