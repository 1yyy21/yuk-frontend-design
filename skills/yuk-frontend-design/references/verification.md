# 接入验证

按改动验证，不以装包成功代替完成。

1. 运行相关构建、类型或既有检查；纯样式不新增镜像实现测试。
2. 检查真实桌面/手机页面：长文本、溢出、弹层、输入与 safe-area。
3. 触发核心交互，检查焦点、键盘、加载/错误/空状态和保存行为。
4. 检查普通和 reduced-motion，按需加载、卸载清理、不阻挡操作。
5. 记录具体来源、版本/源码路径、许可证据、适配原因和验证结果。

报告区分安装、源码接入、静态检查、浏览器验证及真实服务/设备。离线数据命中不是视觉验收，模拟交互不证明真实服务。评审只输出问题；实现请求修复范围内问题后交付。付费、部署和发布遵循授权。
